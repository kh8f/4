# الخزنة — تطبيق إدارة أموال شخصي

تطبيق ويب (HTML/CSS/JS خام، بدون أي مكتبات خارجية) يعمل بالكامل بدون إنترنت.
كل البيانات تُخزَّن على الجهاز نفسه عبر `localStorage` — لا يوجد أي اتصال بأي خادم.

## الملفات
- `index.html` — هيكل الشاشات كلها (الرئيسية، العمليات، الأهداف، الإحصائيات، الإعدادات)
- `style.css` — نظام التصميم (الألوان، الخطوط، الحركات، الوضع الليلي)
- `app.js` — كل منطق التطبيق (تخزين، حسابات، رسوم بيانية SVG يدوية، قفل PIN...)
- `sw.js` — Service Worker يخزّن ملفات التطبيق للعمل بدون إنترنت في المتصفح
- `assets/` — الشعار (SVG + PNG بأحجام متعددة)
- `fonts/` — خط Cairo مضمّن محليًا (لا يحتاج إنترنت أبدًا)

## تجربته الآن
افتح `index.html` مباشرة في أي متصفح (كروم على الجوال أفضل لمعاينة الشكل الحقيقي)،
أو استخدم أي سيرفر محلي بسيط:
```
npx serve .
```

## تحويله إلى APK (بدون إنترنت داخل التطبيق)
بما إن التطبيق لا يستخدم أي CDN أو API خارجي، يصلح مباشرة مع **Capacitor**:

```bash
npm install
npx cap sync android
npx cap open android
```
بعدها تبني الـ APK من Android Studio مباشرة (Build > Build Bundle(s)/APK(s) > Build APK(s)).
أيقونة التطبيق والشاشة الافتتاحية (Splash) الأصليتين محدّثتين بالفعل بالشعار الجديد.

## الجديد في هذه النسخة

### الهوية البصرية
- **شعار جديد** مصمم خصيصًا للتطبيق (خزنة بباب ذهبي دوّار) — مستخدم في أيقونة الأندرويد
  (بكل الأحجام والأشكال التكيّفية Adaptive Icon) وفي شاشة اللودينق.
- **شاشة لودينق (Splash)** عند فتح التطبيق: شعار يتحرك بتأثير Pop-in، حلقات توهج نابضة،
  عنوان وخط فرعي يظهران بحركة تدريجية، ونقاط تحميل متحركة — قبل ما يدخل المستخدم للتطبيق.
- **شاشة Splash أصلية** (على مستوى أندرويد نفسه) بنفس الهوية — خلفية خضراء داكنة + الشعار،
  لكل أحجام الشاشات والاتجاهين (عمودي/أفقي).

### الخطوط
- خط **Cairo** العربي الأنيق مضمّن مباشرة داخل ملفات التطبيق (أربعة أوزان: عادي، شبه بولد،
  بولد، إكسترا بولد). ما يحتاج تحميل من الإنترنت إطلاقًا — يشتغل من أول تشغيل حتى بدون نت.
- فيه أيضًا Service Worker (`sw.js`) يخزّن كل ملفات التطبيق في المتصفح بعد أول تحميل،
  فلو جربته كصفحة ويب عادية بدل تطبيق، يشتغل بعدها بدون إنترنت أيضًا.

### الوضع الليلي/النهاري
- زر تبديل سريع بأيقونة شمس/قمر في أعلى الشاشة الرئيسية (بالإضافة للمفتاح في الإعدادات).
- انتقال سلس بين الوضعين بدل التغيير المفاجئ.

### تأثيرات وحركات جديدة
- تأثير تموّج (Ripple) عند الضغط على أي زر في التطبيق.
- دخول تدريجي متتابع لعناصر القوائم (العمليات، الأهداف) بدل الظهور الفجائي.
- تكبّر بسيط لرقم الرصيد عند تغيّره.
- قصاصات ورقية احتفالية (Confetti) عند الوصول لهدف ادخار أو تمنية بالكامل 🎉.

### مصدر/سبب الإيداع (جديد)
عند تسجيل عملية دخل، تقدر تحدد **سبب الإضافة**: راتب، كسبتها، هدية، بعت شي، استرداد،
مكافأة، أو أخرى. يظهر السبب في قائمة العمليات، وفي الإحصائيات فيه بطاقة "مصادر الدخل"
تلخّص من وين جا دخلك كل شهر.

### مصروفات متكررة (اشتراكات)
عند تسجيل مصروف، تقدر تعلّمه "متكرر شهريًا" (زي اشتراك نتفليكس مثلاً). لما يجي وقته الشهر
الجاي، يظهر تذكير في الشاشة الرئيسية بزر "تسجيل الآن" يسجّل العملية بضغطة وحدة.

### بحث وإحصائيات إضافية
- شريط بحث في شاشة العمليات (يبحث بالملاحظة أو اسم التصنيف أو مصدر الدخل).
- بطاقتا نظرة سريعة في الإحصائيات: أكثر تصنيف صرفت فيه، ومتوسط صرفك اليومي.

## ميزات النسخة الأساسية (موجودة من قبل)
- رصيد حالي + دخل/مصروف الشهر، وشكل "خزنة" SVG تفاعلي يتحرك حسب الرصيد
- تسجيل عمليات (دخل/مصروف) بتصنيف، ملاحظة، تاريخ
- تصنيفات جاهزة + إمكانية إضافة/حذف تصنيفات مخصصة بألوان
- قائمة تمنيات + أهداف ادخار بتاريخ مستهدف وحساب المبلغ اليومي المطلوب
- إحصائيات: مخطط دائري للمصروفات حسب التصنيف، مخطط أعمدة دخل/مصروف لآخر 4 أشهر، متابعة حدود الميزانية
- تنبيه تلقائي عند تجاوز حد الميزانية لأي تصنيف
- اختيار العملة، قفل برمز PIN من 4 أرقام
- تصدير/استيراد نسخة احتياطية JSON، وحذف كل البيانات

## أفكار للمرحلة القادمة
- مزامنة اختيارية عبر Google Drive
- دعم أكثر من "خزنة" (حسابات متعددة: نقدي، بنك، توفير)
- تصدير تقرير PDF
- تعديل عملية موجودة بدل الحذف وإعادة الإدخال
